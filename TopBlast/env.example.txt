# ============================================
# TOPBLAST - Robinhood Chain / Pons Configuration
# ============================================
# Minimum to run a live listing:
#   MONGODB_URI, TOKEN_MINT_ADDRESS (0x, a Pons launch), TOKEN_SYMBOL,
#   TOKEN_DECIMALS=18, PAYOUT_WALLET_PRIVATE_KEY (0x), CHAIN_NETWORK=mainnet.
#
# Two things are strict, and both fail loudly rather than misbehaving:
#   1. Pons is MAINNET ONLY. There is no Pons deployment on Robinhood testnet,
#      so CHAIN_NETWORK=testnet makes every payout cycle refuse to run.
#   2. Automatic creator-fee claiming needs the payout wallet to BE the
#      launch's creatorFeeRecipient. If it isn't, TopBlast refuses to claim
#      rather than sending someone else's fees anywhere.
#
# Local dry run against live mainnet data (reads only, signs nothing):
#   EXECUTE_PAYOUTS=false, then npm run dev and open /<your-slug>.
#   Rankings, VWAPs, pool balance and the buyback quote are all real; the
#   cycle stops just before it would broadcast.
# ============================================

# ============================================
# BIRDEYE
# ============================================
# Robinhood Chain IS supported (x-chain: robinhood) for token prices and
# trades, but NOT for holder lists — those come from chain logs either way.
#
# What the key buys you on Pons listings: cost basis for wallets that buy
# AFTER a launch graduates to Uniswap v4. The bonding curve emits exact
# per-buyer trades; the v4 pool does not (its Swap event names the router,
# not the trader), and Birdeye resolves the trader for us. Without the key
# those wallets simply are not ranked — safe, but they never win.
# Pre-graduation listings need nothing here.
# REQUIRED for production: set BIRDEYE_API_KEY on Vercel + WORKER_OWNS_INDEXING=true.
# Without both, leaderboard polls still hit Helius Enhanced (~100 credits/call).
# Get key: https://bds.birdeye.so → Security tab
# Local probe: npm run birdeye:probe -- <mint>
# Live holder refresh interval per tenant in worker cron (milliseconds, default 60000)
# HOLDER_REFRESH_INTERVAL_MS=60000
# Idle tenant (paused timer, no eligible, unfunded pool) — default 15 min
# HOLDER_IDLE_REFRESH_INTERVAL_MS=900000
# Force Birdeye balance refresh on idle tenants after this age (default 30 min)
# HOLDER_IDLE_SNAPSHOT_MAX_AGE_MS=1800000
# Active tenant max snapshot age before Birdeye re-fetch (default 5 min)
# HOLDER_ACTIVE_SNAPSHOT_MAX_AGE_MS=300000
# Recompute eligibility when price moves at least this % (default 0.5)
# HOLDER_PRICE_CHANGE_THRESHOLD_PCT=0.5
# Top wallets fetched from Birdeye per refresh (default 150 — enough buffer before top-50 persist)
# BIRDEYE_HOLDER_FETCH_MAX=150
# Winner-ranked rows stored + shown on leaderboard (default 50)
# LEADERBOARD_PERSIST_MAX=50
